# Poppins

Local copy of `apps/mobile/assets/fonts/Poppins-Regular.ttf`, shared by the
primary heading styles (ADR-111). Source: Google Fonts, `ofl/poppins`.
`Poppins-SemiBold.ttf` is copied from the same mobile font directory for the
600-weight blue emphasis in the shared Home design; primary titles remain 400.
License: SIL Open Font License, included in `Poppins-OFL.txt`.

Served locally; no external font provider or runtime download dependency.
