# Fuentes del cartel

Poppins Regular400 y SemiBold600 proceden de Google Fonts (`ofl/poppins`),
con licencia OFL en Poppins-OFL.txt. ADR-111 extiende Regular a todos los títulos
principales de la UI; SemiBold conserva el remate azul de Inicio. La web sirve
una copia idéntica del Regular local. Roboto del cartel conserva su uso anterior.

Roboto Regular/Bold se incluyen para generar PDFs sin descargar fuentes durante la operación. Se usan exclusivamente en el documento, sin cambiar AppTheme ni la fuente del sistema en la UI.

Procedencia: paquete oficial de fuentes de Flutter3.35.3, versión `flutter_infra_release/flutter/fonts/3012db47f3130e62f7cc0beabff968a33cbec8d8/fonts.zip`, disponible en https://storage.googleapis.com/flutter_infra_release/flutter/fonts/3012db47f3130e62f7cc0beabff968a33cbec8d8/fonts.zip . Licencia Apache2.0 en Roboto_LICENSE.txt. Se conserva el nombre real con mayúsculas para Linux.
