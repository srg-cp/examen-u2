## Criterios de aceptación originales

- [x] Puedo enviar un avistamiento desde la app o la ficha web, sin instalación ni cuenta obligatoria en el flujo público.
- [x] El formulario registra hora real del evento, ubicación, origen y precisión cuando corresponda, comentario y foto opcional.
- [x] Si deniego ubicación o cámara, puedo seleccionar un punto manual y continuar sin foto o usando la galería.
- [x] La fecha futura se rechaza; un reporte tardío se admite y se identifica como tal.
- [x] Dos envíos con la misma clave crean un único avistamiento y se muestra confirmación tras guardarlo.
- [x] Un caso cerrado o no disponible rechaza nuevos reportes ordinarios y el flujo público aplica límites contra abuso.
