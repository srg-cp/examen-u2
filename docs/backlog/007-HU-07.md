## Criterios de aceptación originales

- [ ] Puedo consultar casos y filtrar por perdido/encontrado, especie, estado, distancia y período.
- [ ] Lista y mapa aplican los mismos filtros y permiten abrir el detalle de un caso.
- [ ] La paginación no repite resultados y el sistema informa cuando no hay coincidencias.
- [ ] Solo se muestran casos visibles y ubicaciones públicas aproximadas; no se exponen coordenadas privadas.
- [ ] Si no concedo ubicación, puedo consultar desde una zona seleccionada manualmente.
- [ ] Se distinguen los estados de carga y error, con opción de reintentar.
