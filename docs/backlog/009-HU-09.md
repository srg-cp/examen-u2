## Criterios de aceptación originales

- [x] El enlace abre una ficha utilizable desde un navegador móvil sin instalar la app.
- [x] La ficha presenta fotos, rasgos, zona aproximada y estado vigente del caso.
- [x] Un token revocado muestra una página neutral sin revelar información privada.
- [x] Un caso cerrado muestra su resolución y no admite nuevos avistamientos ordinarios.
- [x] El QR contiene un identificador opaco; no incluye datos personales en su contenido.
- [x] La ficha permite acceder al formulario de avistamiento cuando el caso lo admite.
