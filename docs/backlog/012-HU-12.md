## Historia de usuario

Como usuario que sigue un caso o una zona, quiero recibir alertas y encontrarlas en una bandeja para consultar novedades aunque no llegue la notificación al teléfono.

## Criterios de aceptación originales

- [x] Puedo seguir y dejar de seguir un caso o una zona conforme a mis preferencias.
- [x] Las alertas se dirigen a suscriptores de casos o zonas pertinentes, sin exigir GPS continuo.
- [ ] La notificación se guarda en la bandeja aunque falle FCM o el token del dispositivo sea inválido.
- [x] Puedo consultar la bandeja, marcar una alerta como leída y abrir el recurso relacionado.
- [x] Los reintentos no duplican las notificaciones y los casos cerrados dejan de generar alertas de búsqueda.
- [x] Las notificaciones no exponen información privada del caso o de sus participantes.
