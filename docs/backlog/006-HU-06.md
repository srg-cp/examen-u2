## Criterios de aceptación originales

- [x] Puedo publicar un encontrado sin conocer al dueño y sin registrar previamente un perfil de mascota.
- [x] El formulario permite registrar fotos, rasgos, fecha, hora, zona y custodia opcional.
- [x] Puedo seleccionar el lugar manualmente y la ficha pública utiliza una ubicación aproximada.
- [x] La publicación no asigna automáticamente propietario ni vincula la mascota por similitud visual.
- [x] Un reintento del mismo envío no duplica el caso y los errores permiten conservar los datos.
