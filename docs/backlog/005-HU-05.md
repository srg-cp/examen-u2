## Criterios de aceptación originales

- [x] Puedo publicar un caso de una mascota que estoy autorizado a gestionar, con fotos, fecha, hora, lugar y características.
- [x] Solo puede existir un caso perdido activo por mascota; la API rechaza una segunda publicación activa.
- [x] Puedo elegir el lugar manualmente si deniego el permiso de ubicación.
- [x] La ficha pública muestra una zona aproximada y no expone domicilio, documentos ni información de salud.
- [x] Repetir el mismo envío con su clave de idempotencia crea un único caso.
- [x] Al completar la publicación se confirma el estado activo; si falla, el formulario conserva los datos para reintentar.
