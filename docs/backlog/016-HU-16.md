## Criterios de aceptación originales

- [ ] El panel permite consultar conteos de casos publicados, avistamientos, cierres y reportes de moderación por período.
- [ ] Los resultados son agregados y no exponen nombres, salud ni ubicaciones exactas.
- [ ] Los casos recuperados se distinguen de cancelados o archivados; las métricas no atribuyen automáticamente una recuperación a la app.
- [ ] Un administrador puede desactivar las funciones habilitadas para este control sin perder los datos existentes.
- [ ] Las consultas y cambios se restringen por rol; las modificaciones de configuración quedan auditadas.
- [ ] Los conteos se comprueban con datos de demostración reproducibles.
