## Criterios de aceptación originales

- [ ] Puedo denunciar una publicación o interacción indicando el motivo y bloquear a un usuario según las reglas de interacción.
- [ ] Un moderador autorizado puede revisar la denuncia y su evidencia en una cola.
- [ ] Ocultar contenido o suspender un recurso exige un motivo y deja registro de actor y fecha.
- [ ] El estado operativo del caso se conserva separado de su visibilidad.
- [ ] Existe una vía de apelación y el historial de decisiones queda disponible para los roles autorizados.
- [ ] El panel y la API rechazan acciones de moderación de usuarios sin permisos; los accesos privados necesarios quedan auditados.
